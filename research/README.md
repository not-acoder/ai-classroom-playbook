# Research record

Files in this directory are versioned with the playbook but excluded from the
built site (see the `exclude:` list in `_config.yml`). They record how the
collection was produced and where the process broke, which is a different
audience from the instructors the playbook is written for.

| File | Contents |
| --- | --- |
| `appendix-a-template-resistance.md` | Where the AGP play template resisted this domain, recorded rather than fixed |
| `appendix-b-candidates-not-drafted.md` | Candidates rejected, held, or deferred, with the reason |

The governing decision behind both: the AGP template was used **unchanged** on
purpose. Pre-patching it would have destroyed the measurement. Resistance is
recorded here so that any future revision of the template is grounded in
observed failures rather than anticipated ones.
