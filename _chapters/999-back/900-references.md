## How to Add References

Add the full citation to the list above in alphabetical order by first author,
with an anchor attached so plays can link to it.

See the [Scribbr citation generator](https://www.scribbr.com/citation/generator/)
to generate citations in the desired style. These examples use APA style.

Attach an anchor to a citation by appending `{:#anchor-name}` to it, using the
form `firstauthor-year`:

```
Mollick, E., & Mollick, L. (2023). *Using AI to ...*
<https://ssrn.com/abstract=4391243>{:#mollick-2023}
```

Then cite it from within a play like this:

```
[(Mollick & Mollick, 2023)](references.html#mollick-2023)
```

**Verify before you add.** Fetch the source and confirm it exists, that the
author and publisher are right, and that it says what you are citing it for.
Several citations in this book were wrong when first produced and were
corrected only because someone opened the document.
