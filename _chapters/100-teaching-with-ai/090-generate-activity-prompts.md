## Intent

The instructor gets a set of candidate active learning activities for a session instead of defaulting to lecture.


## Problem

Active learning is well evidenced and unevenly practised, and the constraint is usually generative rather than motivational. Designing an activity that fits a specific concept, a specific room, and a specific number of students takes preparation time that the instructor does not have on the day. Faced with that, the session defaults to lecture, which is always available and requires no new design.


## Solution

The instructor asks the AI for candidate in class activities or writing prompts for a specified concept, class size, and session length, and selects from the set rather than designing from nothing. The instructor supplies what the model cannot: whether the activity will work with this class, in this room, given what these students already know.


## Applicability

Works well in:

+ Large lecture courses where the instructor wants to break up the session
+ Courses where the instructor is confident with content but not with activity design
+ Sessions being revised term to term rather than designed from scratch

Tradeoffs and limitations:

+ Generated activities are frequently generic and repeat the same few structures such as think pair share regardless of the concept, so specify what you have already used
+ Timing estimates are unreliable and activities routinely take longer than suggested
+ Activities assume a room configuration and a class size that may not match yours, so state both

Not a good fit when:

+ Room, seating, or class size makes most active formats impossible and the constraint is physical rather than generative


## How to Implement

Steps 2, 4, and 5 are drafted.

1. Enlist the AI to create ideas for in class activities or writing prompts for the concept you are teaching.
2. _(Drafted)_ State class size, session length, and room configuration, since the model will otherwise assume a small flexible seminar.
3. Treat the output as ideas rather than a plan, and develop the chosen activity into your own material.
4. _(Drafted)_ Name the activity structures you have already used this term and ask for something different, or you will get the same few formats repeatedly.
5. _(Drafted)_ Halve your confidence in any suggested timing and plan a stopping point.
