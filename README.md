# The Playbook of AI in the Classroom

Practices instructors can adopt when teaching computing in the presence of
generative AI. Built with the method from Paper 2; currently v1.1, 29 plays in
four chapters.

| Path | What it is |
| --- | --- |
| `_chapters/` | The plays, one Markdown file each, grouped into chapter folders |
| `CHANGELOG.md` | What changed in each version, and corrections owed elsewhere |
| `_config.yml`, `Gemfile` | Jekyll site settings |

Steps marked _(Drafted)_ were written by the drafter, not taken from a source.
Each play's Evidence Status and Freshness sections say how well supported and
how current it is.

The prompts used to build and score it are in `PlaybookPrompts`.
